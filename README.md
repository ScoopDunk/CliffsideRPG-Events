# Cliffside RPG Events

Past events from [Cliffside RPG](https://cliffsiderpg.net), saved as single HTML files you can play on your own.

## How to play one

1. Click **Download** next to the event you want.
2. On the page that opens, click the download button (the arrow at the top right of the file).
3. Open the downloaded file in any web browser. Nothing to install.
